# Название проекта
Привет! Это проект для работы с вакансиями headhunter

## Использование
Проект состоит из 5 функциональных и 4 тестовых модулей, для того чтобы запустить проект выполните команду python3 main.py. Для успешного выполнения программы строго следуйте инструкциям которые вы будете получать после ответа на вопрос 

### Требования
Для установки и запуска проекта, необходим Python3.13+.

### Установка зависимостей
Для просмотра зависимостей, воспользуйтесь файлом requirements.txt или если его нет выполните команду pip freeze > requierments.txt:


## Тестирование
